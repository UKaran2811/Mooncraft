MOONCRAFT IMAGES DIRECTORY
==========================

You can drop your custom product or header images directly into this folder (e.g., using the file uploader) to serve them on your website.

Any image placed here will be accessible to the frontend code instantly. For example:
- A file named `my_product.jpg` placed in this folder will be referenceable in code/images as:
  `/images/my_product.jpg`

Enjoy crafting with Mooncraft!
